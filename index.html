01

LitFinder

Live GitHub

LLM-powered literature search over OpenAlex's 300M+ scholarly works—describe what you need in plain language. Semantic retrieval with citation expansion and a cross-encoder reranker lifted nDCG@10 from 0.55 to 0.95 on a 32-query benchmark. An agent mode plans its own searches through function calling, and the same tools ship as an MCP server. Grew out of my Edinburgh dissertation, now deployed on AWS.

03

ORCA Hand — RL Pipeline & Failure Diagnostics

GitHub

A ~3,000-line PPO and MuJoCo pipeline for cube reorientation on a 17-actuator dexterous hand: 14 parallel environments, curriculum, and scripted-policy checks and regression tests that gate every training job. Root-caused a 100M-step run that gained nothing—a reset bug was handing a do-nothing policy 26% free successes—then matched the previous best in a fifth of the steps. An observation redesign took 45° reorientation from 37–39% to 62–65%, confirmed across 24 runs with paired two-seed controls. USC team project.
